# Subir v0.14 a GitHub

1. Descomprime `Brawl-Stars-Lab-v0.14-update.zip`.
2. Abre el repositorio `Brawl-Stars-Lab-` en GitHub.
3. Pulsa **Add file → Upload files**.
4. Arrastra todos los archivos y carpetas descomprimidos.
5. Escribe: `Añadir prueba de resiliencia del draft v0.14`.
6. Pulsa **Commit changes**.
7. Vercel desplegará la actualización automáticamente.

## Comprobación posterior

1. Abre `/draft`.
2. Elige un mapa e introduce los picks en orden.
3. Comprueba el panel **Prueba de respuestas probables** antes de un pick que todavía pueda recibir counter.
4. Revisa resiliencia, media, peor escenario y counters directos.
5. Prueba **Usar pick robusto** y las dos alternativas.
6. Completa el draft y verifica que el panel desaparece cuando ya eres last pick y no quedan respuestas rivales.
7. Usa `Ctrl + F5` si continúa apareciendo la versión anterior.
