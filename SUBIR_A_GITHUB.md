# Subir v0.8 a GitHub

1. Descomprime `Brawl-Stars-Lab-v0.8-update.zip`.
2. Abre el repositorio `Brawl-Stars-Lab-` en GitHub.
3. Pulsa **Add file → Upload files**.
4. Arrastra todos los archivos y carpetas descomprimidos.
5. Escribe el mensaje: `Añadir Live Review v0.8`.
6. Pulsa **Commit changes**.
7. Vercel desplegará la actualización automáticamente.

Después del despliegue, abre `/live`. El navegador debe estar en HTTPS para solicitar compartir pantalla; el dominio de Vercel ya utiliza HTTPS.
