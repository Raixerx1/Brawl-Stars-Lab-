# Cómo subir la actualización v0.4 a GitHub

1. Descarga `Brawl-Stars-Lab-v0.4-update.zip`.
2. Descomprime el ZIP.
3. Abre el repositorio `Brawl-Stars-Lab-` en GitHub.
4. Pulsa **Add file → Upload files**.
5. Arrastra todo el contenido descomprimido, conservando las carpetas.
6. En el mensaje del commit escribe:

   `Añadir Draft Coach y pool personal v0.4`

7. Pulsa **Commit changes**.
8. Vercel iniciará automáticamente un nuevo despliegue.

## Qué debes comprobar después

- `/draft`: modo rápido, builds, líneas, simulación rival, bans y guardado.
- `/pool`: configuración personal persistente.
- `/compare`: comparación de tres brawlers.
- Fichas de mapas: nueva lectura visual de líneas.
- El menú lateral debe mostrar “Mi pool” y “Comparador”.

No subas el ZIP cerrado: sube los archivos y carpetas que contiene.
