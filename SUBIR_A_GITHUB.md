# Subir v0.13 a GitHub

1. Descomprime `Brawl-Stars-Lab-v0.13-update.zip`.
2. Abre el repositorio `Brawl-Stars-Lab-` en GitHub.
3. Pulsa **Add file → Upload files**.
4. Arrastra todos los archivos y carpetas descomprimidos.
5. Escribe: `Añadir colas Ranked y doble pick v0.13`.
6. Pulsa **Commit changes**.
7. Vercel desplegará la actualización automáticamente.

## Comprobación posterior

1. Abre `/draft`.
2. Cambia **Cola Ranked** entre SoloQ, Dúo y Trío.
3. Comprueba que cambian las recomendaciones y su nivel de coordinación.
4. Avanza hasta una fase con dos picks aliados consecutivos.
5. Verifica el panel **Doble pick recomendado**.
6. Prueba **Usar primero** y **Simular/Aplicar pareja**.
7. Usa `Ctrl + F5` si continúa apareciendo la versión anterior.
