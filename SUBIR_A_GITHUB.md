# Subir v0.4.3 a GitHub

1. Descomprime `Brawl-Stars-Lab-v0.4.3-update.zip`.
2. Abre el repositorio `Brawl-Stars-Lab-`.
3. Pulsa **Add file → Upload files**.
4. Arrastra todos los archivos y carpetas descomprimidos.
5. Mensaje: `Priorizar counters en Draft Assistant v0.4.3`.
6. Pulsa **Commit changes**.
7. Vercel desplegará automáticamente.
8. En el ordenador, recarga una vez con Ctrl+F5 para sustituir la caché anterior.
