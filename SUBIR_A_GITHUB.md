# Subir v0.12.1 a GitHub

1. Descomprime `Brawl-Stars-Lab-v0.12.1-update.zip`.
2. Abre el repositorio `Brawl-Stars-Lab-` en GitHub.
3. Pulsa **Add file → Upload files**.
4. Arrastra todos los archivos y carpetas descomprimidos.
5. Escribe: `Corregir recomendación inmediata y sesgo de RT v0.12.1`.
6. Pulsa **Commit changes**.
7. Vercel desplegará la actualización automáticamente.

## Comprobación posterior

1. Abre `/draft`.
2. Añade o elimina un pick.
3. Comprueba que el brawler recomendado aparece justo debajo de la barra de seis picks.
4. Verifica que el nombre cambia con el mapa y los picks rivales.
5. Durante tu turno, prueba **Usar pick**.
6. Fuerza una recarga con `Ctrl + F5` si continúa apareciendo la interfaz anterior.
