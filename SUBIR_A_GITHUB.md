# Instrucciones sin programar

## Opción sencilla desde la web de GitHub
1. Descomprime el ZIP.
2. Abre tu repositorio `Brawl-Stars-Lab-`.
3. Pulsa **Add file → Upload files**.
4. Arrastra **todo el contenido** de la carpeta, no la carpeta ZIP cerrada.
5. Espera a que termine la carga.
6. En “Commit changes”, escribe: `Primera versión de Brawl Draft Lab`.
7. Pulsa el botón verde **Commit changes**.

GitHub permite subir archivos desde el navegador, pero puede ser incómodo con muchas carpetas. Si no conserva bien la estructura, usa GitHub Desktop:

## Opción recomendada: GitHub Desktop
1. Instala GitHub Desktop e inicia sesión.
2. Pulsa **File → Clone repository** y selecciona `Brawl-Stars-Lab-`.
3. Abre la carpeta clonada.
4. Copia dentro todos los archivos de este proyecto.
5. Vuelve a GitHub Desktop.
6. Escribe el resumen `Primera versión de Brawl Draft Lab`.
7. Pulsa **Commit to main** y después **Push origin**.

## Publicarla
1. Abre vercel.com e inicia sesión con GitHub.
2. Pulsa **Add New → Project**.
3. Importa `Brawl-Stars-Lab-`.
4. Pulsa **Deploy**.
5. Abre la dirección generada en Safari y usa **Compartir → Añadir a pantalla de inicio**.
