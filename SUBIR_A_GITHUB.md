# Subir v0.4.1 a GitHub

1. Descomprime `Brawl-Stars-Lab-v0.4.1-update.zip`.
2. En GitHub abre el repositorio `Brawl-Stars-Lab-`.
3. Pulsa **Add file → Upload files**.
4. Arrastra todos los archivos y carpetas descomprimidos.
5. Mensaje del commit: `Completar pool de mapas Ranked v0.4.1`.
6. Pulsa **Commit changes**.
7. Vercel desplegará la actualización automáticamente.
