# Subir v0.8.1 a GitHub

1. Descomprime `Brawl-Stars-Lab-v0.8.1-update.zip`.
2. Abre el repositorio `Brawl-Stars-Lab-` en GitHub.
3. Pulsa **Add file → Upload files**.
4. Arrastra todos los archivos y carpetas descomprimidos.
5. Escribe: `Completar roster de Counters v0.8.1`.
6. Pulsa **Commit changes**.
7. Vercel desplegará la actualización automáticamente.

Después del despliegue, abre `/counters` y busca `Bolt`. El contador superior debe mostrar `106/106` sin filtros.
