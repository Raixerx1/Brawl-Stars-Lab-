# Subir v0.10 a GitHub

1. Descomprime `Brawl-Stars-Lab-v0.10-update.zip`.
2. Abre el repositorio `Brawl-Stars-Lab-` en GitHub.
3. Pulsa **Add file → Upload files**.
4. Arrastra todos los archivos y carpetas descomprimidos.
5. Escribe: `Mejorar Auto Review adaptativo v0.10`.
6. Pulsa **Commit changes**.
7. Vercel desplegará la actualización automáticamente.

## Prueba recomendada

1. Abre `/live`.
2. Comparte únicamente la ventana del juego.
3. Usa sensibilidad **Media**.
4. Espera a que la salud indique **Buena**.
5. Confirma o rechaza al menos cinco detecciones.
6. Comprueba que aparecen inferencias de secuencia cuando varios eventos ocurren próximos.
