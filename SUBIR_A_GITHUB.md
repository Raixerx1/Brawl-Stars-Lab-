# Subir v0.12 a GitHub

1. Descomprime `Brawl-Stars-Lab-v0.12-update.zip`.
2. Abre el repositorio `Brawl-Stars-Lab-` en GitHub.
3. Pulsa **Add file → Upload files**.
4. Arrastra todos los archivos y carpetas descomprimidos.
5. Escribe: `Añadir modelo estructural de first picks v0.12`.
6. Pulsa **Commit changes**.
7. Vercel desplegará la actualización automáticamente.

## Comprobación posterior

1. Abre `/draft`.
2. Selecciona Rustic Arcade sin picks:
   - Piper;
   - 8-Bit;
   - Brock.
3. Comprueba que aparecen las métricas de apertura, arbustos, muros, ruptura y pasillos.
4. Abre la ficha de cualquier mapa para ver:
   - estado inicial;
   - transformación tras wallbreak;
   - puntuaciones y alternativas.
5. Si aparece la versión anterior, usa `Ctrl + F5`.
