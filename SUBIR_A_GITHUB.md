# Subir v0.11 a GitHub

1. Descomprime `Brawl-Stars-Lab-v0.11-update.zip`.
2. Abre el repositorio `Brawl-Stars-Lab-` en GitHub.
3. Pulsa **Add file → Upload files**.
4. Arrastra todos los archivos y carpetas descomprimidos.
5. Escribe: `Revisar tier list counters y first picks v0.11`.
6. Pulsa **Commit changes**.
7. Vercel desplegará la actualización automáticamente.

## Comprobación posterior

1. En `/meta`, confirma que la tier list aparece encima de los nerfs.
2. En `/counters?brawler=bolt`, verifica Gale, Damian, Charlie, Otis y Lou como amenazas.
3. En `/draft`, selecciona Rustic Arcade sin picks y comprueba Piper, 8-Bit y Brock.
4. Si aparece una versión antigua, fuerza la recarga con `Ctrl + F5`.
