# Subir v0.9 a GitHub

1. Descomprime `Brawl-Stars-Lab-v0.9-update.zip`.
2. Abre el repositorio `Brawl-Stars-Lab-` en GitHub.
3. Pulsa **Add file → Upload files**.
4. Arrastra todos los archivos y carpetas descomprimidos.
5. Escribe: `Añadir Auto Review Beta v0.9`.
6. Pulsa **Commit changes**.
7. Vercel desplegará la actualización automáticamente.

## Primera prueba

1. Abre `/live`.
2. Mantén activada **Detección automática**.
3. Usa sensibilidad **Media**.
4. Comparte únicamente la ventana del juego o del emulador.
5. Espera a que termine la calibración.
6. Revisa las detecciones y elimina los falsos positivos antes de guardar.

La captura de pantalla requiere HTTPS. El dominio de Vercel ya utiliza HTTPS.
